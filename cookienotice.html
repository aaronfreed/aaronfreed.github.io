Notice on cookie usage

This website uses cookies for one reason and one reason only: so that users may personalize how they view this website without having to reselect their choices every time they load any page on this website. They’re also entirely opt-in: they’re only set if users choose non-default settings. They’re stored entirely on users’ local devices, and I have implemented no code to track user data. I couldn’t do that with my cookies anyway, since, converted to a human-readable format, they contain only data on:

  • Color scheme: light mode, dark mode, or system default
  • Primary font: FiraGO or Atkinson Hyperlegible Next

(Current defaults are bolded.)

If you wish to personalize your viewing experience on this site without cookies, you can create a user agent stylesheet to do so, but this is a complicated process that I wouldn’t recommend to non-programmers, and explaining it is beyond the scope of this notice. Cookies are the most feasible way existing web standards provide to persist user preferences across multiple pages on a website (or even after a refresh). Sadly, they’re also widely misused for surveillance, resulting in many users distrusting them across the board. They have legitimate uses, though, and this is one of them. I’ll simply reiterate that I don’t store any data on people who view my website and have no interest in tracking their viewing habits, much less profiting off them.
